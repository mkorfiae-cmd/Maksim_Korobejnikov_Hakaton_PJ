# Микросервис для инференса ML-модели

Веб-приложение на базе Flask для выполнения предсказаний с использованием обученной модели машинного обучения. Сервис предоставляет REST API и простой веб-интерфейс для тестирования модели на пользовательских JSON-запросах.

Модель используется для прогнозирования вероятности конверсии пользователя на основе характеристик сессии и поведения на сайте.

# Руководство по развертыванию

## 1. Создание виртуального окружения

Для изоляции зависимостей рекомендуется использовать виртуальное окружение Python.

Выполните команду в корневой директории проекта:

```bash
python -m venv venv
```

## 2. Активация виртуального окружения

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## 3. Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

Основные используемые библиотеки:

* Flask
* pandas
* scikit-learn
* catboost
* joblib

## 4. Подключение модели

Поместите файл обученной модели:

```text
model_catboost.pkl
```

в корневую директорию проекта.

Структура проекта:

```text
project/
│
├── app.py
├── model_catboost.pkl
├── requirements.txt
└── templates/
    ├── index.html
    └── result.html
```

Если файл модели отсутствует или повреждён, API предсказаний будет возвращать ошибку загрузки модели.


## 5. Запуск приложения

Запустите Flask-приложение:

```bash
python app.py
```

После запуска сервис будет доступен по адресу:

```text
http://127.0.0.1:5000/
```


# Возможности сервиса

Сервис поддерживает:

* загрузку обученной ML-модели;
* REST API для выполнения предсказаний;
* обработку JSON-запросов;
* веб-интерфейс для ручного тестирования модели;
* отображение вероятности конверсии пользователя.

# Формат входных данных

Модель принимает JSON-объект с признаками пользовательской сессии.

Пример:

```json
{
    "utm_source": "other",
    "utm_medium": "cpc",
    "device_category": "mobile",
    "visit_hour": 19,
    "is_paid": 1,
    "hits_count_log": 2.1972
}
```

# Результат предсказания

После отправки запроса сервис отображает:

* вероятность конверсии
* предсказанный класс
    - `0` — конверсия отсутствует
    - `1` — пользователь совершит конверсию
